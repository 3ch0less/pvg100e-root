# Restore and unbrick

Everything here assumes you have the Step 4 backup. If you do not, stop and make one.

## Reaching EDL when the phone will not boot

1. Hold power ~15 s to force off.
2. Hold power through 3 to 4 restart cycles until the menu appears.
3. Short-press to highlight **recovery**, long-press to select.
4. In recovery choose **Emergency download mode**.
5. Verify on the host: USB device `05c6:9008` present.

## Restore a single partition (example: unroot)

```sh
python edl.py w boot backup/boot.bin --memory=eMMC --loader=pepito_vdf_fh.bin
python edl.py reset --loader=pepito_vdf_fh.bin
```

Boots you back to 100 percent stock. Any partition works the same way
(`recovery`, `system`, `vendor`, `modem`, ...).

## Restore everything

The backup contains `rawprogram0.xml` (generated by `--genxml`). Two options:

```sh
# option A: edl, all partitions in one go
python edl.py wl backup --memory=eMMC --loader=pepito_vdf_fh.bin

# option B: qdl (xerootg fork, pepito branch)
qdl --storage emmc pepito_vdf_fh.bin backup/rawprogram0.xml
```

Option B is the flow the Linux guides document with QFIL on Windows; the same XML works in
QFIL if you ever sit at a Windows machine (Flat Build, press Cancel at the patch prompt).

## Really dead (no EDL either)

If even the recovery menu will not come up, the last resort is the hardware test points
that force 9008: two pads under the rear-camera flash, bridged while plugging in USB.
Photos and the full procedure are on the neko.ink Pepito page (linked in README Resources).
The author of that page recovered a hard-bricked unit exactly this way. You need to open
the phone, so only go there if the software paths are truly exhausted.

## After a restore

- Stock boot restored -> Magisk gone, everything else as it was.
- Full restore -> factory state, including your original userdata (with its original
  encryption binding, so your old PIN works again).
- Re-rooting later is Step 5 onward; your backup stays valid.
